# 🚗 Car Brand Classification using Deep Learning

## 📌 Project Overview
This project is an AI-based Car Brand Classification system developed using Deep Learning and Computer Vision techniques.  
The model predicts the brand of a car from an input image.

The system is trained on multiple car brand images and performs image classification to identify the correct brand.

---

## 🎯 Features
- Car brand prediction from images
- Deep Learning based image classification
- Image preprocessing and prediction visualization
- User-friendly testing workflow
- Supports multiple car brands

---

## 🛠 Technologies Used
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
